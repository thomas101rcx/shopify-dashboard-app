2. Files You Need

A. Shopify Data Export (required — Data Prep page)

Export your Shopify orders as a CSV or XLSX file. The file must contain these columns:

Required columns in your Shopify export
ColumnExampleWhy
Emailcustomer@gmail.comUsed to group orders by customer
Billing CompanyAcme CorpAccount name (may be empty — rules will fill it)
Created at2026-03-15Order date — used to assign quarter (Q1–Q4)
Lineitem quantity3Number of items — this is what gets summed
Lineitem price49.99Used to filter out low-value items
Lineitem nameDeluxe SkimmerUsed to filter accessories/services
Lineitem skuSKU-123Kept for reference
Tip: Export all orders for the year (or the period you want to report on). The app will filter and aggregate them automatically.

B. Rules File (required — Data Prep page)

A YAML, JSON, or Python file that tells the app how to transform your data. The project includes a ready-made rules file:

Included: rules_shopify.yaml YAML rules file — ready to use, no editing needed

This rules file will:

  1. Keep only the columns listed above
  2. Remove accessory/service items (replacement, extended, bag, warranty, foam)
  3. Remove items priced below $240 (with an exception for complimentary skimmers)
  4. Fill in missing Billing Company from the email domain (e.g. john@acmecorp.com → acmecorp.com)
  5. For free email domains (gmail, yahoo, etc.), use the full email as the company name
  6. Cast columns to correct types (int, float, datetime)
  7. Compute Total amount = quantity × price
  8. Summarize by Billing Company + Created at (sum quantities, sum amounts, list SKUs)

C. Your Pivot Table (required — Merge & Overview pages)

Your existing pivot_table.xlsx workbook. This is the master dashboard that gets updated with new data each period.

pivot_table.xlsx Your existing Excel workbook with sheets: Overview, Lost Account, Count, 24Y 25N, Account Label Definition, Duplicate Accounts
Important: Always keep a backup of your pivot_table.xlsx before merging. The Merge page creates a new file — it does not modify your original.

3. Page 1: Data Prep

Sidebar → Data Prep

Transform raw Shopify export data into clean, aggregated output ready to merge into your pivot table.

1 Upload your rules file

In the sidebar, click "Rules file" and select your rules file:

  • rules_shopify.yaml — included with the app, ready to use
  • Or your own custom rules file (.yaml, .json, or .py)

You should see a green confirmation: "Loaded 9 rule(s)".

2 Upload your data file(s)

In the sidebar, click "Data files" and select one or more CSV/XLSX files.

If your file has multiple sheets, a radio button appears to pick which sheet to use.

3 Review the transformation

For each file you uploaded, the app shows:

  • Raw data preview — first 50 rows of the original file
  • Transformed result — data after all rules are applied

Check that the Billing Company column is filled in and the Created at dates look correct.

4 Download or send to Merge

Three buttons appear below each result:

  • Download CSV — save the result as a CSV file
  • Download XLSX — save the result as an Excel file
  • Send to Merge — pass the result directly to the Merge page (no download needed)
Done! Your data is now cleaned and aggregated by company + date. Move to the Merge page.

4. Page 2: Merge

Sidebar → Merge

Combine your Data Prep output with your existing pivot table to produce an updated workbook.

1 Upload your pivot_table.xlsx

Click "Pivot table file" and select your existing pivot_table.xlsx.

2 Provide Data Prep output

You have two options:

  • Sent from Data Prep page — if you clicked "Send to Merge" on the Data Prep page, the app uses that data automatically. No upload needed.
  • Upload a file — click "Data Prep output file" and select the CSV or XLSX you downloaded from the Data Prep page.
3 Review the three merge tabs

Tab 1: Side-by-side Merge

Shows your Overview data alongside the Data Prep quarterly columns:

  • All original Overview columns (Account, Qty_2023, Growth, etc.)
  • ETL_Q1 through ETL_Q4 — quantities from your Data Prep output by quarter
  • ETL_Total — total for the period

New accounts (in Data Prep but not in your original Overview) are marked as "new" in the row count.

Tab 2: Updated Overview

Shows your Overview with Data Prep quantities added to the correct quarter column:

  • Jan–Mar orders → added to Qty_2026_1
  • Apr–Jun orders → added to Qty_2026_2
  • Jul–Sep orders → added to Qty_2026_3
  • Oct–Dec orders → added to Qty_2026_4
  • Qty_2026_ = sum of all four quarters (recomputed)

Growth labels are preserved from your original file. The 25-26 growth is only recomputed if Data Prep changed a zero quantity to a positive one (new or reactivated account).

Tab 3: Updated Count

Shows the Count tab categories computed from the updated Overview:

CategoryMeaning
Total AccountTotal number of accounts
LostAccounts with prior history but no 2026 purchases
New_26Accounts with 2026 purchases but no prior history
No Purchase 2026 / Not LostNo 2026 purchases, not labeled Lost
Already Purchased 2026Has 2026 purchases

If your Count sheet has previous columns, a delta table shows the change vs the last column.

4 Download the updated pivot table

On the Updated Overview tab, click "Generate Updated Pivot XLSX" to create a full workbook. Then click the download button that appears.

The generated workbook includes:

  • Overview sheet — rebuilt with merged data, SUM/COUNTIF formulas, preserved growth labels
  • Count sheet — new snapshot column appended (labeled with the date range, e.g. 0601-0618)
  • All other sheets — copied as-is from your original file
Done! You now have an updated Shopify_Pivot_Table_updated.xlsx. This becomes your new working pivot_table.xlsx for next time.

6. End-to-End Walkthrough

Here's the complete flow from raw Shopify data to updated dashboard:

1 Export data from Shopify

In Shopify Admin → Orders → Export. Choose CSV format. Export all orders for the reporting period.

2 Go to Data Prep page

Sidebar → Data Prep.

3 Upload rules_shopify.yaml and your Shopify CSV

Rules file in the first uploader, data file in the second. Review the transformed output.

4 Click "Send to Merge"

This passes the result directly to the Merge page. No download needed.

5 Go to Merge page

Sidebar → Merge. Upload your current pivot_table.xlsx. The Data Prep result is already loaded.

6 Review the three merge tabs

Check Side-by-side Merge, Updated Overview, and Updated Count for accuracy.

7 Click "Generate Updated Pivot XLSX" → Download

On the Updated Overview tab. Save the downloaded file. This is your new pivot table.

8 Go to Overview page to verify

Sidebar → Overview. Upload the newly generated file. Browse all tabs to confirm everything looks correct.

Complete! Your pivot table is updated with the latest Shopify data. Use this file as your starting point next period.

7. Troubleshooting

ProblemSolution
"Missing column: Billing Company"Your export may not have this column. The rules file will fill it from email — just make sure Email is present.
"Missing column: Lineitem quantity"Check your Shopify export includes line-item level data, not just order-level.
"Rules error" on uploadCheck your YAML syntax. Use rules_shopify.yaml as a reference.
File won't upload (XLSX)The app tries multiple Excel engines. If it fails, save your file as CSV and upload that instead.
New accounts showing in warningThis is expected — accounts in your Data Prep output that don't exist in your pivot table yet. They'll be added to the updated file.
Growth labels look wrongLabels are preserved from your original file. Only 25-26 growth is recomputed when a zero becomes positive. SOS labels are never auto-assigned.
Count tab shows wrong numbersCount categories are computed from the updated Overview. Check that the Overview data looks correct first.
Best practice: Run the Data Prep page first, review the output, then move to Merge. Always keep a backup of your pivot_table.xlsx before generating a new one.
